⏱️ 3. Süre Ayarı: 45 Dakikayı 24 Saate (veya Farklı Bir Süreye) Çıkarma

Escrow sipariş sayfasındaki dairesel geri sayım sayacı ve otomatik onay süresi 3 dosyada düzenlenebilir:

1. Sipariş Sayfası Başlangıç Değeri

Dosya: app/orders/page.tsx (Satır 136)

// ESKİ (2570 saniye = ~42 dakika 50 saniye):
<CountdownTimer initialSeconds={2570} />

// YENİ (24 saat = 24 * 3600 = 86400 saniye):
<CountdownTimer initialSeconds={86400} />

2. Sayaç Bileşeni (Saat : Dakika : Saniye Desteği)

Dosya: components/ui/CountdownTimer.tsx (Satır 11-30)

// 24 saatlik referans:
const totalSeconds = 86400;

// Saat hesabı ekleme:
const hours = Math.floor(timeLeft / 3600);
const minutes = Math.floor((timeLeft % 3600) / 60);
const seconds = timeLeft % 60;

// Ekranda gösterme:
{formatPad(hours)}:{formatPad(minutes)}:{formatPad(seconds)}
